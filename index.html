Eigenvalues and expectation values

Part 1 diagonalises an n×n matrix. Part 2 computes ⟨x⟩, ⟨p⟩, ⟨p²⟩ and ⟨E⟩ for a wavefunction. All calculations use functions written in this page (see the script at the bottom of the source).

1. Eigenvalues and normalised eigenvectors

Enter a real symmetric matrix (for example a Hamiltonian). The Jacobi rotation method is used.

2. Expectation values

Pick a wavefunction ψ(x). The program normalises it, then evaluates the integrals numerically with the trapezoid rule.

Units are set by the ħ and m you enter (default ħ = m = 1). The potential is taken as V = 0 inside the region, so ⟨E⟩ = ⟨p²⟩ / 2m.
